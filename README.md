
# Face-Based Smart Attendance System Using Siamese Networks and One-Shot Learning

## Project Description

This project is designed to automate student attendance using face recognition technology.

It uses Siamese Neural Networks and One-Shot Learning to identify individuals from facial images and record attendance automatically.

## Technologies Used
- Python
- Deep Learning
- Siamese Neural Networks
- One-Shot Learning
- OpenCV

## Main Features
- Face Detection
- Face Recognition
- Automatic Attendance
- Student Identification
- Attendance Recording

## Objective

To develop an efficient and automated attendance system using facial recognition and deep learning techniques.
